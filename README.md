# Vignesh Hospital, Tumkur

Website for Vignesh Hospital (Yallapura, Madhugiri Road, Tumkur).

Next.js 14 · Tailwind · GSAP ScrollTrigger · Lenis · Framer Motion · React Three Fiber.

- `npm run dev` for local development
- `npm run build` exports a static site to `out/` (Netlify: `netlify.toml` is set up)

All hospital facts (timings, fees, doctors, stats) live in `lib/content.ts`. Photos are in `public/images`.
